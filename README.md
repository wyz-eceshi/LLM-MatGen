# LLM-MatGen

材料结构生成工具，支持 10 类生成器、轻量结构检查和来源记录，提供 CLI、Python 与 MCP 接口。

## 下载与安装

[下载 wheel 安装包](https://github.com/wyz-eceshi/LLM-MatGen/releases/download/v0.1.0/llm_matgen-0.1.0-py3-none-any.whl)

[下载完整源码包](https://github.com/wyz-eceshi/LLM-MatGen/releases/download/v0.1.0/llm_matgen-0.1.0.tar.gz)

需要 Python 3.10 或以上。在安装包目录执行：

```powershell
python -m pip install ./llm_matgen-0.1.0-py3-none-any.whl
llm-matgen --help
```

安装时联网下载依赖。项目名称已恢复为 LLM-MatGen，保留 dft-structure-building 命令作为兼容入口。完整源码与文档位于发布附件 tar.gz 中。
